# 01 - OOP Python Tasks

Four programs that practice classes, methods and encapsulating data.

| Task | Class | What it does |
|---|---|---|
| 1 | `Student` | Stores scores, calculates the average and returns a letter grade |
| 2 | `PhoneBook` | Adds, finds, deletes and lists contacts, and asks before overwriting an existing contact |
| 3 | `ShoppingCart` | Adds and removes items, shows the cart, counts items and calculates the total |
| 4 | `TaskManager` | Adds tasks with priority, lists all, completed and pending tasks, and finds high-priority tasks |

**Run:** `python oop_tasks.py`
**Concepts:** classes, `__init__`, methods, lists, dictionaries, tuples, loops, string formatting
