# 02 - Pandas & Matplotlib Data Analysis

Each problem processes the data with Pandas first and then plots the result with Matplotlib.

| File | Problem | Charts |
|---|---|---|
| `problem_01_student_grades.py` | Total, percentage and grade for 10 students, with grade counts | Pie, histogram |
| `problem_02_profit_analysis.py` | Monthly profit, best and worst month, quarterly revenue vs cost | Line (with highlighted best month), grouped bar |
| `problem_03_study_hours_vs_marks.py` | Removes invalid rows, labels High/Low performers, compares average study hours | Scatter, bar |
| `problem_04_temperature_analysis.py` | Celsius to Fahrenheit, Cold/Pleasant/Hot days, weekly averages | 2x2 subplots (line, histogram, pie, bar) |
| `problem_05_expense_tracker.py` | `ExpenseTracker` class: category totals, spending share, warning above 30% | Pie, sorted bar |
| `scatter_with_regression_line.py` | Fits a line to data with `numpy.polyfit` | Scatter plus fitted line |

**Run:** `python problem_01_student_grades.py` (and so on)
**Concepts:** DataFrames, adding columns, filtering, `sum`, `mean`, `max`, `value_counts`, `sort_values`, data cleaning
